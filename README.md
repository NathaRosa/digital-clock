# Digital Clock

Relógio digital desenvolvido em Java utilizando JavaFX.

O projeto foi desenvolvido como uma forma de praticar conceitos de Java, JavaFX e atualização dinâmica de informações na interface gráfica.

## Funcionalidades

* Exibição da hora atual em tempo real.
* Atualização automática do relógio.
* Interface gráfica utilizando JavaFX.
* Exibição de horas, minutos e segundos.

## Objetivo

Projeto desenvolvido para praticar programação em Java e desenvolvimento de interfaces gráficas com JavaFX, explorando conceitos como atualização de componentes em tempo real, manipulação de data e hora e organização de aplicações desktop.
